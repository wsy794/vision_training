# 任务2：合成旋转视频的参数拟合

## 模型

角速度模型：`omega(t) = b + A*sin(Omega*t + phi)`

## 估计参数

| 参数 | 值 | 单位 |
|------|----|----|
| A | 0 | rad/s |
| b | 1.37291 | rad/s |
| Omega | 0.996056 | rad/s |
| phi | 0.177423 | rad |

速度变化周期 T = 2*pi/Omega = 6.30806 s

## 误差指标

- RMSE = 0.39411 rad/s
- 有效样本数 = 1438
- 参与计算帧范围：1 ~ 1438

## 方法

1. 在 HSV 空间用青色阈值提取目标，取最大轮廓中心。
2. 计算 `theta = atan2(c_y - y, x - c_x)`，并展开为连续角。
3. 中心差分求角速度。
4. 用 Ceres Solver 自动求导拟合，约束 A>0、Omega>0。
